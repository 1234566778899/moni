# Moni – sitio web

Landing estática de **Moni – Gastos y Préstamos** (app iOS de finanzas personales).

- `index.html` – página principal
- `privacidad.html` – política de privacidad (URL para App Store Connect)
- `soporte.html` – soporte (URL para App Store Connect)

Sin build: HTML + CSS. Se despliega en Vercel como sitio estático.
